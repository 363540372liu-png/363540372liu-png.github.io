# Polar Explorer V2.1 使用与追溯

## 写文章

在 Pages CMS 选择本仓库和要编辑的分支，进入「文章管理」：

1. 新建 Markdown 文章，填写标题、摘要、发布时间。
2. 在必填「所属区域」下拉框中选择一个区域，不能多选。区域和标签独立，不会根据标题或正文自动判断。
3. 标签按需要逐项添加，可自由输入多个。
4. 正文支持 Markdown 富文本；特殊语法使用 Source 模式。MDX 仍通过源码编辑，避免 JSX/组件被富文本处理。
5. 草稿默认开启。完成后关闭草稿并保存；时间到达且部署完成后，文章会进入对应区域与全站列表。

四个值：dry-valleys（麦克默多干谷）、station-1810（1810号科考站）、port-lockroy（洛克罗伊港）、inaccessibility（不可接近之极）。旧文允许没有 region，继续在全站展示，不自动归类。编辑旧文时 CMS 会要求手动选择；无需批量修改旧文。

单区域每页 6 篇。草稿及尚未到发布时间的内容复用 AstroPaper 原有过滤逻辑。静态站点的定时发布需要在时间到达后再次构建，未新增定时后台。

图片上传保持 public/images → /images，未配置 frontmatter 保持 merge:true。关于页面保持禁止 CMS 删除/改名。

目前未登录托管 Pages CMS 实际执行新建/保存；已按官方 select 的 values/name/label、multiple:false 格式配置，并验证等效 frontmatter、标签数组、日期、草稿与分类分页的实际 Astro 构建。后台首次使用仍需确认保存体验，不应把本地验证视为后台端到端验收。

官方格式：https://pagescms.org/docs/configuration/fields/select/

## 地图定位

NOAA 图像未修改：EPSG:3031，完整方形范围 [-3400000,-3400000,3400000,3400000] 米，2048×2048，无旋转或裁剪。图像边缘 CSS 淡出不改变坐标变换。

x% = (E + 3400000) / 6800000 × 100；y% = (3400000 - N) / 6800000 × 100。

scripts/maps/project_regions.py 使用 pyproj（WGS84/EPSG:4326 → EPSG:3031，always_xy）生成 src/data/region-positions.json。src/data/regions.ts 保存统一名称、介绍、颜色和图标，组件直接使用计算位置，点击目标保持48px。

## 维护内容与字体

src/data/polar.ts 中 exploring 的三个模块均为明确占位，可以手动更新；projects 支持 title、description、status、tags、可选cover和href。未提供成果或链接时显示待补充，不生成虚构项目。区域介绍与主题仅按用户定义。

英文字体 Manrope 从 Google Fonts 官方仓库取得并制作 Latin WOFF2 子集，约29KB，font-display:swap。中文优先本地 Source Han Sans SC/Noto Sans CJK SC，回退到系统无衬线，不下载巨大中文包。代码继续使用原有等宽字体。字体不归入通用源码MIT许可，Manrope与Inconsolata均附独立SIL OFL。

- https://github.com/google/fonts/tree/main/ofl/manrope
- public/fonts/Manrope-OFL.txt
- public/fonts/Inconsolata-OFL.txt

子集复现：从官方仓库下载 Manrope[wght].ttf，安装 fonttools 与 brotli 后运行 fontTools.subset，参数 --flavor=woff2 --unicodes=U+0000-024F,U+2000-206F,U+2190-21FF。没有新增浏览器运行时依赖。

为保留用户/Pages CMS保存的Markdown格式，Prettier跳过src/content下作者Markdown；Astro构建继续校验内容与Schema，所有应用源码仍受格式检查。文章正文没有改写，最新main上的About更新已保留。
